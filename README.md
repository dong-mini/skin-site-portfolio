# Skin Detection Web Prototype (2025)

이 레포지토리는 제가 제작한 피부 분석 사이트의 프로토타입 결과물을 정리한 포트폴리오용 저장소입니다.

## 📌 프로젝트 개요
- 피부 톤/트러블 분류 테스트용 사이트 화면 제작
- 초기 UI 프로토타입 구성
- AI 기반 기능 일부 테스트
- 향후 AWS 서버와 연동해 실시간 분석 기능 추가 예정
